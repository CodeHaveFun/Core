# Set up ERROR CODE (Feature for changing language soon)

## Overview
Error Code had 3 types

| Type | Description |
|:----:|:------------|
| CLI  | Errors related to command-line input, missing arguments, incorrect flags, or environment issues. |
| Compile | Errors that occur during compilation or interpretation due to syntax violations, type mismatches, or unresolved references. |
| Runtime | 	Errors that occur while the program is executing, often due to logical flaws, invalid operations, or unexpected states. |



### Error Code For CLI
| Error Codes | Description |
|:-----------:|:------------|
| `CI001N`   | Not a command of Core |
| `CI002N`   | Missed vaild arguments |
| `CI003N`   | Path file is invaild |
| `CI004N`   | File is not existed |
