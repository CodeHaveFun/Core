## 🌟 About Core

**Core** is a modern programming language built completely from scratch.

The main goal of Core is to make programming more accessible by allowing developers to write source code using multiple natural languages while maintaining a single compiler architecture.

Core focuses on:

- Simplicity
- Readability
- Extensibility
- Friendly compiler diagnostics
- Native Unicode support

> **Write code in your own language.**

---

# 🎯 Vision

Programming should not be limited by human language.

Core aims to let developers choose their preferred programming language without changing how programs are compiled or executed.

Whether you speak English, Vietnamese, Japanese, or another supported language, the compiler should understand you.

# 🏛 Compiler Architecture

Core is designed with a modular compiler pipeline.

```
Source Code
      │
      ▼
 Unicode Reader
      │
      ▼
    Lexer
      │
      ▼
 GAMMAR WORDS
      │
      ▼
    Parser
      │
      ▼
     AST
      │
      ▼
 Semantic Analysis
      │
      ▼
 Intermediate Representation
      │
      ▼
 Optimizer
      │
      ▼
 Code Generator
      │
      ▼
 Executable
```

The architecture is designed so that adding a new programming language requires minimal changes outside the lexical layer.
