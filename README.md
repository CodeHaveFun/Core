## What is Core?
Core is **a programming language** and a development platform designed to make programming easier for beginners, students, etc to understand while still providing powerful control over the system. 

Core will focus on three main things:
- **Simple Syntax** : make code easier to read and write, expecially for beginners and students.
- **Multi-language support for message errors** : Core allows developers to change the language used for error messages, making them easier to understand for people who are not good or uncomfortable when reading English errors.
- **Visual Flow Analysis - VFA** (My idea - not implemented yet): A software program will integrate with Core to help developers visually represent data flow, variables, conditions, and functions through a flowchart generated from their source code for debugging.

## What problems does Core solve?

### 1. Complex syntax

- C/C++ provides powerful control over hardware, but its syntax can
be difficult to understand, especially for beginners.

- Core aims to provide a **simpler** and more **readable** syntax while
still allowing developers to work with **powerful system-level** features.

### 2. Language barriers

- Programming languages are usually designed around a specific natural
language, making them less accessible to developers who are not
comfortable with that language.

- The core system supports multiple national languages ​​for its **errors messages**. (except for syntax)

### 3. Understanding program flow (integeted VFA)

- Traditional source code can make it difficult to visualize how a
program actually flows.

- Core integrates Visual Flow Analysis (VFA) to help developers
understand the flow of their programs.
